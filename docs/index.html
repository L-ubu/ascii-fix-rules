02What it teaches your AI

◆ Align columns

Every row has delimiters at the same positions. The model counts before it draws.

◆ Consistent style

Never mix border characters in the same block — no + corners with ║ walls.

◆ Proper padding

One space on each side of every cell, always. Content never touches the walls.

◆ Matching borders

Borders span the full width of the widest content, corners included.

◆ CJK & emoji widths

Fullwidth characters count as two columns — the classic alignment breaker, handled.

◆ Self-check

The model verifies alignment before showing ASCII art, instead of you spotting it after.

04Why it exists

The decisions worth knowing about, written down.

Rules are cheaper than repairs

A rules file costs zero tokens at runtime and fixes the problem at generation time — no post-processing pass, no extra tool in the loop.

Any assistant that reads rules

Cursor and Claude Code are first-class, but anything that ingests project-level instructions can follow them.

Pairs with the fixer

For art that already shipped broken, there's ascii-fix — the deterministic cleanup CLI. Belt and suspenders.
